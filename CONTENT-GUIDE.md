# Portfolio Content Guide

This package was rebuilt from the supplied syllabi and portfolio PDFs.

## Editing the writing

- Edit `work/portfolio-content.json` in the source project.
- Save the file, then run `work/build_portfolio.py` to refresh the site and downloadable ZIP package.
- The JSON file contains the homepage copy plus every project and coursework page title, summary, overview, topics, figures, and takeaways.
- Do not edit the generated HTML files in this package because a rebuild replaces them.
