# Document Uploads (`assets/docs`)

Use this folder for PDFs and other downloadable documents used by your GitHub Pages site.

## Suggested subfolders
- `resume/` — your resume/CV files
- `projects/` — reports, posters, design docs for projects
- `coursework/` — lab reports, writeups, class deliverables
- `certificates/` — optional certifications or awards

## Naming tips
- Use lowercase and hyphens in filenames (example: `kaleb-martiny-resume.pdf`)
- Avoid spaces and special characters
- Keep files reasonably small for faster loading

## Example links in Markdown
```md
[Resume PDF](/assets/docs/resume/kaleb-martiny-resume.pdf)
[CFD Report](/assets/docs/projects/airfoil-cfd-report.pdf)
```

## Notes
- GitHub Pages can link directly to PDFs and many other file types.
- To display a PDF inline, use an `<iframe>` or `<object>` in a page and keep a direct download link as backup.
